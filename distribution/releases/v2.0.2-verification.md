## Build and quality checks

- All 38 JVM tests passed. Both release lint variants passed with zero errors.
- A clean source checkout at the tag built `assembleStoreRelease -PkronoStoreUnsigned=true` with both signing paths pointing to nonexistent files and no local signing directory.
- `apksigcopier compare --unsigned` succeeded comparing the published Linux CI store APK with that macOS unsigned rebuild.
- fdroidserver 2.4.5 returned zero fatal source findings after removing the unused `legacy-rn/` archive from the disposable scan checkout, and zero binary findings for the published store APK.
- The published original edition updated directly from GitHub v1.6.5 with `adb install -r`. Its app ID (`10229`) and first-install timestamp stayed unchanged; installed versionCode became 202.
- The store edition updated from the published v2.0.1 APK with `adb install -r`. Its app ID (`10230`) and first-install timestamp stayed unchanged; installed versionCode became 202.
- Both editions launched on an isolated Android emulator data image with `getconf PAGESIZE` reporting 16384. The store screen rendered current contest data, with no AndroidRuntime crash logged.

These are upstream verification results, not an F-Droid build-server result or a guarantee of store acceptance. The complete review and product limitations remain in [STORE_REVIEW.md](../STORE_REVIEW.md).
